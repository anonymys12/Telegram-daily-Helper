# Dayli Helper

**Dayli Helper** — персональний Telegram-бот, який допомагає у щоденних нагадуваннях, надсилає мотиваційні цитати та повідомляє погоду у вашому місті.

## Особливості
- Надсилання випадкових мемних фраз.
- Отримання мотиваційних цитат через API.
- Поточна погода за обраним містом (API Open-Meteo).
- Щоденні ранкові повідомлення.
- Інтерактивне меню з кнопками в Telegram.

## Встановлення
1. Клонувати репозиторій:
   
   git clone https://github.com/твій-логін/Dayli-helper.git


2. Створити віртуальне середовище:

   bash
   python -m venv venv
   
3. Активувати середовище:

  bash
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   
4. Встановити залежності:

   bash
   pip install -r requirements.txt
   
5. Створити файл `.env` та додати токен бота:

   
   BOT_TOKEN=ваш_токен
   

## Використання

Запуск бота:

bash
python main.py


Після запуску бот підключається до Telegram і стає готовим до використання.

Команди бота:

* `/start` — початкове меню.
* Кнопки меню дозволяють отримати фразу, цитату або поточну погоду.

## Структура коду

* `main.py` — основний код бота.
* `cities_by_region.py` — словник з областями та містами для погоди.
* `.env` — токен бота.
